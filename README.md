# 汉典单字查询扩展
Manifest V3 浏览器插件，悬浮识别网页汉字，一键跳转汉典查询。

## 功能
1. 点击插件图标进入开启模式，工具栏绿色ON标识已激活，各标签页状态互相独立
2. 鼠标悬浮汉字，弹出黄色提示框显示汉字
3. 点击汉字，新标签打开汉典 zdic.net/hans/该字
4. 开启模式页面鼠标变为小手
5. 按 Esc 快速退出（输入框内不会误触发）

## 文件列表
- manifest.json 扩展配置
- background.js 后台状态管理
- content.js 页面脚本
- style.css 样式
- icon.png 图标

## 安装
1. 把全部文件放到本地文件夹
2. 浏览器打开扩展管理页，开启开发者模式
3. 加载已解压扩展，选中文件夹（src目录）
4. 打开网页，点插件图标使用

## 使用
- 开启：点插件图标，出现绿色ON
- 查询：鼠标移到汉字，点击
- 关闭：再次点图标 / 网页按 Esc

## 局限
- canvas、图片文字、Shadow‑DOM内部文字无法识别，仅支持普通网页文本
- 修改代码后记得重新加载扩展 + 刷新网页
